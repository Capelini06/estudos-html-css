PYTHON

  1. Inspirada na comédia: Foi batizada em homenagem ao grupo de humor britânico Monty Python. O criador, Guido van Rossum, lia os roteiros do programa Monty Python's Flying Circus enquanto desenvolvia a linguagem.
  2. Existe um manifesto oculto: Se você digitar import this em qualquer terminal Python, um poema chamado "The Zen of Python" será exibido. Ele contém as 19 filosofias de design da linguagem, como "Bonito é melhor que feio".
  3. Antigravidade embutida: Outro "Easter Egg" famoso: se você digitar import antigravity no terminal, o Python abrirá automaticamente o navegador em uma tirinha clássica do site XKCD sobre a facilidade de programar na linguagem.
  4. Sem chaves: Ao contrário da maioria das linguagens modernas, o Python não usa chaves {} para definir blocos de código. Ele usa estritamente a indentação (espaços em branco), tornando o código visualmente limpo e obrigando o programador a ser organizado.
  5. Linguagem espacial: O Python é amplamente utilizado pela NASA e pela SpaceX para análise de dados, simulações de órbitas e automação de sistemas de solo.

JAVASCRIPT

  1. Criada em tempo recorde: Foi desenvolvida em apenas 10 dias em maio de 1995 por Brendan Eich. Ele precisava pressas criar uma linguagem de script para o navegador Netscape Navigator.
  2. Estratégia de marketing: O nome original era Mocha, depois mudou para LiveScript e, finalmente, JavaScript. A mudança final foi uma jogada de marketing para pegar carona no enorme sucesso que a linguagem Java fazia na época, embora as duas não tenham nenhuma relação técnica.
  3. O erro histórico que virou regra: No JavaScript, se você rodar o comando typeof null, o resultado retornado será "object". Isso é um bug do motor original da linguagem que nunca pôde ser corrigido porque quebraria milhões de sites existentes no mundo.
  4. Padronização oficial: O JavaScript "puro" e padronizado não se chama JavaScript, mas sim ECMAScript. O nome JavaScript é uma marca registrada que hoje pertence à Oracle.
  5. Domínio absoluto na web: É a única linguagem de programação que roda nativamente em praticamente todos os navegadores web do planeta, o que a torna a linguagem mais popular do ecossistema front-end.
